# Integrated capability provenance

This product adapts selected reasoning patterns from Robin's skills. It does not copy
private databases, full global skill folders, runtime identities or machine paths.
These are product-owned adaptations; original skill installations are not prerequisites.

| Source capability | Adaptation | Explicitly excluded |
| --- | --- | --- |
| paper-3w-research | query logging, DOI deduplication, WHY/HOW/WHAT review and source selection | Hermes-only delegation, old paths, automatic claims from abstracts |
| paper-method-sop | protocol-unit extraction, parameter cards, missing-data markers | Notion database ids, automatic writes, missing legacy scaffold scripts |
| research-gap-to-idea | source curation, evidence/interpretation separation, comparability checks, uncertainty-to-falsification mapping | full idea-generation workflow, forced novelty ranking or three idea types |
| paper-explain-concept | optional deep reading of decisive operations and assumptions | full-paper reading report for every search hit |
| opendataloader-pdf-md / pdf-extract | optional extraction backend; built-in pdftotext import and page labels | mandatory Java/OCR service or assumed installed executables |
| Zotero workflows | optional user-selected read-only evidence input | mandatory personal library, API keys or automatic ingestion |

Experimental-results synchronization and NMR inference are future extensions, not shipped
as available assay analysis. No experiment-results sync, Notion integration, GelMA dialysis
calculator, Bayesian probabilities, FEM simulation or compound-identification engine runs.
Actual chemical evaluation remains distinct from these document and reasoning capabilities.

Code ancestry: pinned Robinharness adapter and Google Research Harness2; see vendor metadata
and NOTICE. Local skill descriptions did not provide standalone license files; rather than
redistribute their packages, this plugin implements its own scoped interfaces and concise
instructions for the authorized use case. Any future third-party code inclusion requires
recorded licensing and attribution.
